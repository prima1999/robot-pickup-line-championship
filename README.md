A robot's one-line pickup line for make.fun's "The Robot Pickup Line Championship" bounty. The program writes a single line — a robot confessing that falling in love voided its own warranty — to /output/entry.txt, where the house judge compares it head to head with the other entries.

## Run it

```sh
node main.ts
```
